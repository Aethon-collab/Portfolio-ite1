AETHON PORTFOLIO — GITHUB PAGES UPLOAD

This version is corrected for a repository where all files are in the root folder.

UPLOAD INSTRUCTIONS
1. Extract this ZIP on your device.
2. Open your GitHub repository Project-ite1.
3. Upload all files inside this folder (not the folder itself) to the repository root.
4. Replace existing files when GitHub asks.
5. Commit the changes and wait a few minutes for GitHub Pages to update.

Keep these files together in the same root folder: index.html, about.html, skills.html, projects.html, contact.html, style.css, script.js, profile.jpg, multimedia-preview.jpg, and .nojekyll.

The HTML pages use relative paths so CSS, JavaScript, and images load from the same repository folder.
